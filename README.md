# 1. 인공지능의 이해
## 탐색과 추론
### 탐색을 활용한 문제 해결
#### 1) 목표에 어떻게 도달할 수 있을까?
- 탐색 트리
  - 인공지능에서 탐색은 모든 문제를 경우의 수로 표현하고, 그래프나 트리 형태로 나타냄.
    - 그래프 : 트리보다 큰 개념
      - **방향성(좌 우 위 아래) X**
      - **순환 O**
      - **루트 노드(부모 노드) n-1개 이상**
      - 트리(탑 다운 방식(위에서 아래로))
        - **순환 X**
        - **방향(탑 -> 다운) O**
        - **루트 노드(부모 노드) 1개**
        - 구조
          - 노드(=데이터): 덩어리
          - 링크: 연결
            
## 탐색의 종류
  - **맹목적 탐색(= 무정보 탐색)**   *상태 공간(=노드(in 트리))
    - 상태 공간의 정보 없이, 모든 상태를 **규칙**(=기계적인 순서)에 따라 모든 상태를 탐색하는 방법.
      - **분기점에서 방향을 무작위로 정함.**
        
    - **깊이 우선 탐색**(DFS(= Deep First search))
      - 컴퓨터는 무조건 단계를 기준으로 노드 1칸씩 전진
        - in 트리, **왼쪽에서 오른쪽의 순서**로 노드를 감.(무조건 링크를 통해서 이동함.)
          *PPT P.37(참고: 왼쪽이 가장 먼저인 알파벳(알파벳이 먼저일수록 값이 작음(작은 순서로 정렬))(= 값이 작은 순서대로 탐색을 함.(in 파일이 정렬된 환경))
      - **왼쪽 가장 아래로 쭉 가고 다음 오른쪽 단계로 감.**(참고: 이미 방문한 노드는 탐색 경로에 기록되지 않음. => 이동 경로 확인할 때 주의)
    - **너비 우선 탐색**(BFS(= Breadth First Search))
      - **DFS보다 느림.**(모든 경우의 수를 보기 때문에 경로를 찾는 것보다 느림(깊이가 너무 깊지 않을 때))
      - **왼쪽에서 오른쪽으로 옆으로 경우를 다 봄.(동일한 깊이에서 활동)**
      - DFS의 좋은 답을 놓치는 단점을 보완하기 위해 가능한 모든 경우의 수를 봄.
      - 방문한 노드는 다시 방문하지 않음.
        *PPT P.43

    - **DFS와 BFS의 차이**
      - 트리 탐색에서는 큰 차이가 없음.
      - DFS는 더 간단한 경로를 놓치는 경로를 놓치고 복잡한 경로를 제시할 수 있음.
        
  - 정보 이용 탐색(= 휴리스틱 탐색 or 경험적 탐색)
    - 상태 공간에서 정보를 활용하며 지능적으로 그래프의 일부만 효과적으로 탐색함으로써 가까운 근삿값을 빨리 찾을 수 있음.
      - 언덕 등반 탐색
      - 최상 우선 탐색
      - A*알고리즘
