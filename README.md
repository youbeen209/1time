# 1. 인공지능의 이해
## 탐색과 추론
### 탐색을 활용한 문제 해결
#### 1) 목표에 어떻게 도달할 수 있을까?
- 탐색 트리
  - 인공지능에서 탐색은 모든 문제를 경우의 수로 표현하고, 그래프나 트리 형태로 나타냄.
    - 그래프 : 트리보다 큰 개념
      - **방향성(좌 우 위 아래) X**
      - **순환 O**
      - **루트 노드(부모 노드) n-1개 이상**
      - 트리(탑 다운 방식(위에서 아래로))
        - **순환 X**
        - **방향(탑 -> 다운) O**
        - **루트 노드(부모 노드) 1개**
        - 구조
          - 노드(=데이터): 덩어리
          - 링크: 연결
