# 1. 인공지능의 이해
## 1) 탐색과 추론
### 1) 탐색을 활용한 문제 해결
#### 1) 목표에 어떻게 도달할 수 있을까?
- 탐색 트리
  - 인공지능에서 탐색은 모든 문제를 경우의 수로 표현하고, 그래프나 트리 형태로 나타냄.
    - 그래프 : 트리보다 큰 개념
      - **방향성(좌 우 위 아래) X**
      - **순환 O**
      - **루트 노드(부모 노드) n-1개 이상**
      - 트리(탑 다운 방식(위에서 아래로))
        - **순환 X**
        - **방향(탑 -> 다운) O**
        - **루트 노드(부모 노드) 1개**
        - 구조
          - 노드(=데이터): 덩어리
          - 링크: 연결
            
## 탐색의 종류
  - **맹목적 탐색(= 무정보 탐색)**   *상태 공간(=노드(in 트리))
    - 상태 공간의 정보 없이, 모든 상태를 **규칙**(=기계적인 순서)에 따라 모든 상태를 탐색하는 방법.
      - **분기점에서 방향을 무작위로 정함.**
        
    - **깊이 우선 탐색**(DFS(= Deep First search))
      - 컴퓨터는 무조건 단계를 기준으로 노드 1칸씩 전진
        - in 트리, **왼쪽에서 오른쪽의 순서**로 노드를 감.(무조건 링크를 통해서 이동함.)
          *PPT P.37(참고: 왼쪽이 가장 먼저인 알파벳(알파벳이 먼저일수록 값이 작음(작은 순서로 정렬))(= 값이 작은 순서대로 탐색을 함.(in 파일이 정렬된 환경))
      - **왼쪽 가장 아래로 쭉 가고 다음 오른쪽 단계로 감.**(참고: 이미 방문한 노드는 탐색 경로에 기록되지 않음. => 이동 경로 확인할 때 주의)
    - **너비 우선 탐색**(BFS(= Breadth First Search))
      - **DFS보다 느림.**(모든 경우의 수를 보기 때문에 경로를 찾는 것보다 느림(깊이가 너무 깊지 않을 때))
      - **왼쪽에서 오른쪽으로 옆으로 경우를 다 봄.(동일한 깊이에서 활동)**
      - DFS의 좋은 답을 놓치는 단점을 보완하기 위해 가능한 모든 경우의 수를 봄.
      - 방문한 노드는 다시 방문하지 않음.
        *PPT P.43

    - **DFS와 BFS의 차이**
      - 트리 탐색에서는 큰 차이가 없음.
      - DFS는 더 간단한 경로를 놓치는 경로를 놓치고 복잡한 경로를 제시할 수 있음.
        
  - 정보 이용 탐색(= 휴리스틱 탐색 or 경험적 탐색)
    - 맹목적은 모든 우선 세팅이 필요하고 용량도 많이 차지함. 그래서 경험적이 효율적임.
    - 상태 공간에서 정보를 활용하며 지능적으로 그래프의 일부만 효과적으로 탐색함으로써 가까운 근삿값을 빨리 찾을 수 있음.
    - 이전 경험이나 지식을 바탕으로 어떤 기준을 판단하여 결정하는 탐색 방법
    - 이때 만들어진 정보를 휴리스틱 정보라고 함.(or 휴리스틱 탐색)
      - 언덕 등반 탐색(HCS)(= 휴리스틱 탐색)
        - 현재 지점에서 경험(값)에 의한 평균 함수 값이 가장 좋은 주변 지점을 하나씩 확장해 나가는 탐색 방법
        - 어떤 값에서 다른 값을 내어 더 좋은 쪽으로 감.
        - 지역적으로도, 전체적으로도 최적의 해를 찾는 데에 적합함.
        - P.53 : 맞는 퍼즐의 개수는 평가 함수라고 지정하고, 평가 함수가 목표 상태에 일치하는 수만큼 값이 일치한 곳에 감.(값이 점점 커지는 대로 감.)
        - 경우의 수를 세고 목표에 가까운 지점으로 감.(평가 함수가 높으면 좋음)
      - 최상 우선 탐색(BFS)(= Best First Search)
        - 언덕 등반 탐색을 개선한 탐색 방법
        - 리스트를 사용하여 리스트 안의 요소 중 가장 유리한 것을 선택.
        - HCS에서 자식 노드보다 부모 노드가 더 좋을 때, HCS와 달리 뒤로 다시 가볼 수 있음.
        - 선택되지 못한 노드도 다시 고려하는 과정을 거침.
        - 작성
            close = [지나간 노드의 집합]
            open = [지나갈 수 있는 노드]
        - 평가 함숫값에 따라 성능이 달라짐.
      - A*알고리즘(A스타 알고리즘)(=알파고)
        *P.64 참고
        - 이전 링크 값까지 더하고 계산
        - 성능에 큰 영향을 미치는 평가 함수를 잘 정해야 함.
        - 최고 우선 탐색에 변수를 하나 더 추가해서 고려할 점을 하나 더 추가함.
          
### 2) 지식의 표현과 추론
#### 1) 인간의 지식을 어떻게 표현할까?
- 지식 : 어떤 대상에 대해 배우거나 실천을 통해 알게 된 명확한 인식이나 이해
- 자연어 : 일상적으로 사용하는 말과 글, 정형화되지 않고 불규칙적(언어) / 일상에서 쓰고 있는 언어적 수단(수어, 바디랭기지)
- 비정형 데이터 : 인간이 주로 사용하는 자연어, 그림 기호, 수식, 도면 등의 데이터(사람이 쓰는 모든 것)
- 정형 데이터 : 수치화되어 있는 데이터
- 컴퓨터에서 활용하기 위해 만든 지식 표현 방법
  - 규칙 기반 전문가 시스템 : 특정 영역의 문제를 해결하기 위해 수준 높은 지식을 적용한 인공지능
  - 의미망 : 노드와 노드 간의 관계를 나타내는 구조. 관계는 링크로 표현함. 지식을 연결된 형태로 구현할 수 있기 때문에 지식을 표현하는 데 적합함.
  - 프레임 : 설명이 다소 부족하다는 노드의 단점을 보완한 것으로, 각 노드의 정보가 자세하게 기술되어 있음.
    - 명제 논리, 술어 논리 등
  - 임베딩(embedding) : 문자를 컴퓨터가 이해할 수 있게 쉽게 바꾼 것
    - 생성기/계산기 필요함.
    - 좌표 간의 거리(리스트로 좌표를 알려줌)를 재본다면 비슷한지 알 수 있음.(점과 점 사이 거리, 코사인 등)
     ex) 추천 알고리즘
    - LLM(Large Language Model) : AI와 대화할 때 쓰임. Attention 알고리즘으로 유사도가 높은 순으로 단어를 구성함.(낮은 유사도도 가능)
#### 2) 규칙과 사실을 활용하여 어떻게 지식을 표현할까?
- 논리 : 말이나 글에서 사고나 추리 등을 이치에 맞게 이끌어 가는 과정이나 원리
- 논리학 : 논리를 연구하는 학문으로 고대 그리스 시대부터 발전해왔고, 현대의 기호 논리학에서는 기호를 이용하여 문장의 참과 거짓을 판정하고 내용을 추론함.
